You need to run the main.py script within a terminal with the arguments that can be learned from CLI help command. You should see the necessary debugging messages and progress bar when the download starts.

Do not try to seed or expect to convert to automatic seeding after download finishes, this is yet to be implemented. Also note that there is a limited number of peers taken from the tracker. Be careful about the linux torrents that you download since Distributed Hash Table (DHT) protocol is not yet implemented you will need a tracker to find peers.
